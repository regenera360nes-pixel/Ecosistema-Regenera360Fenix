# Examples

Este directorio contiene ejemplos de uso del ecosistema médico.

## Ejemplos Disponibles

### 1. WhatsApp Integration (`whatsapp_example.py`)
Demuestra cómo enviar mensajes, recordatorios y consejos de salud via WhatsApp.

```bash
python examples/whatsapp_example.py
```

### 2. AI Medical Assistant (`ai_assistant_example.py`)
Muestra cómo usar la IA de Huggingface para consultas médicas.

```bash
python examples/ai_assistant_example.py
```

### 3. Complete Workflow (`complete_workflow_example.py`)
Demuestra un flujo completo de interacción con pacientes integrando todas las plataformas.

```bash
python examples/complete_workflow_example.py
```

## Notas

- Los ejemplos requieren configurar las variables de entorno en `.env`
- Algunos ejemplos están comentados para evitar envíos reales sin configuración
- Descomentar y agregar datos reales para probar funcionalidad completa
