# Configuración del Ecosistema Médico Regenera360

Este directorio contiene archivos de configuración para el ecosistema.

## Archivos de Configuración

- `settings.py`: Configuración general de la aplicación
- `logging_config.py`: Configuración de logs
- `database.py`: Configuración de base de datos

## Variables de Entorno

Copie el archivo `.env.example` a `.env` y configure las variables necesarias:

```bash
cp ../.env.example ../.env
```

Luego edite `.env` con sus credenciales reales.
